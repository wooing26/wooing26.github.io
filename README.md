# 박우영 · Game Client Developer

Unity 게임·VR 클라이언트 개발 포트폴리오. 빌드 도구 없이 동작하는 HTML/CSS/JavaScript 사이트입니다.

## 구성

- `index.html`: 첫 소개, 학력·교육과 경력, 프로젝트·기술 사례, 개발 철학, 다운로드, 연락처
- `gallery.js`: 영상·이미지 팝업, 영상 우선 표시, 이미지 사전 디코딩·캐시, 닫기와 포커스 복귀
- `style.css`: 반응형 레이아웃, 키보드 포커스, 모션 감소 및 인쇄 스타일
- `motion.css`: 궤도·프로젝트 콜라주, 이미지 중심 케이스 스터디, 모션 랩과 반응형 보강
- `motion.js`: 스크롤 등장·현재 메뉴·읽기 진행률, 모션 정지/재생, Canvas 물리 모션
- `assets/`: 제공된 포트폴리오 PDF에서 추출한 실제 프로젝트 화면
- `downloads/`: 원본 이력서·포트폴리오 PDF

## GitHub Pages

`wooing26.github.io` 저장소의 `main` 브랜치 루트에 파일을 배치하고 Settings → Pages → Deploy from a branch → main / (root)로 설정합니다.

공식 설정 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 수정

내용은 `index.html`, 색상·배치는 `style.css`에서 수정합니다. PDF 교체 시 같은 경로를 유지하고 페이지 수·용량 표기도 함께 갱신합니다. 새 프로젝트나 경력은 사실 확인 후 추가합니다. 세 최신 프로젝트의 시작 월은 최초 커밋 기준입니다.

다운로드 PDF에는 원본의 연락처 등 개인정보가 포함됩니다. 사이트와 PDF는 공개 열람용입니다. 개별 게임 자산을 배포하는 사이트가 아니며 이미지의 권리는 각 권리자에게 있습니다. 팬게임은 비공식 학습 프로젝트입니다.

## 로컬 확인

이 폴더에서 `python -m http.server 4173`을 실행하고 `http://localhost:4173`을 엽니다. 서버 없이 `index.html`을 직접 열어도 본문과 다운로드가 동작합니다.

검증: `python check_site.py` (표준 라이브러리만 사용).

## 디자인과 모션

기존 다크 올리브·살구·라임 팔레트와 실제 프로젝트 이미지를 사용합니다. 별도 빌드 도구나 JavaScript 라이브러리는 필요하지 않습니다.

- 첫 화면의 궤도·프로젝트 이미지, 기술 키워드 띠와 데이터 계층 신호에 움직임을 적용했습니다.
- 학력·교육과 회사 경력을 프로젝트보다 먼저 배치했습니다. 대학 전공은 큰 밝은 카드로, 교육 과정은 개별 카드로 표시하며 모바일에서도 제목과 기간을 읽기 쉽게 구성했습니다.
- 모션 랩은 포트폴리오의 물리·시스템 주제를 재해석한 웹 개념 모션입니다. 원본 게임의 실행 결과나 정밀 물리 시뮬레이터가 아닙니다.
- Canvas를 누르면 입력 방향으로 샷을 보내고, `다시 샷` 버튼은 키보드로도 조작할 수 있습니다.
- `모션 일시정지`로 연속 모션을 멈춥니다. 운영체제의 `동작 줄이기` 설정을 따르며, 이 경우 샷 입력은 애니메이션 대신 궤적의 정적 결과를 표시합니다.
- 화면 밖의 반복 CSS 모션과 Canvas 렌더링을 중지하고, 비활성 탭에서도 불필요한 렌더링을 멈춥니다. Canvas 해상도 배율은 최대 2배입니다.
- JavaScript가 꺼져 있어도 소개·프로젝트·경력·기술 상세와 5개 PDF 다운로드를 읽고 사용할 수 있습니다. 이미지 팝업과 모션 랩의 샷 조작에는 JavaScript가 필요합니다.
- 프로젝트 갤러리 템플릿에 YouTube 영상 링크가 있으면 카드를 눌렀을 때 영상부터 표시합니다. 현재 Potion Maker·SKYFALL Resistance·Last Flame Keepers에 적용되며, `이미지` 선택으로 기존 화면도 볼 수 있습니다. 영상은 사용자가 재생하고, 이미지 전환·팝업 닫기 시 플레이어를 제거해 재생을 중지합니다. 재생 제한에 대비한 YouTube 원본 링크도 제공합니다.

검증 범위: 320/390/768/1024/1440px에서 가로 넘침 확인, 9개 이미지 팝업과 Escape·포커스 복귀, 이력서 실제 다운로드, 모션 정지·재생, 기술 상세 펼치기, 정적 자산·링크 검증과 JavaScript 구문 검사.
